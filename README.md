# Yi Zhang's personal homepage

Source for [cindy0725.github.io](https://cindy0725.github.io/).

This is a static HTML/CSS site. GitHub Pages serves it directly; `.nojekyll` disables the previous AcademicPages build. No package installation is required.

## Edit and preview

- Edit `index.html` to update the biography, publications, teaching, or reviewing.
- Edit `assets/site.css` to adjust the responsive layout.
- Keep publication thumbnails in `images/research/`.
- Update the footer date when changing the page.

From the repository root, run `python3 -m http.server 8000`, then open `http://localhost:8000`.

GitHub Pages should continue to publish from the root of the `master` branch. The separate 3DGeoDet project site is linked by its public URL.
